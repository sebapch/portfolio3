# Sebastián Medina — professional portfolio

Next.js portfolio focused on software engineering, applied AI and systems integration.

Requires Node.js 22 or later and pnpm. Run pnpm install --frozen-lockfile, then pnpm dev. Local preview: http://localhost:8080. Validation: pnpm lint and pnpm build. Production server: pnpm start.

Public routes: / (overview and CV downloads), /about (experience and education), /projects (professional work). /articles redirects to /projects. The legacy /dummy.pdf URL now serves the real English résumé.

Public CV variants omit a telephone number. Update both language PDFs and the compatibility PDF together. Do not publish private repository links, client data or unverified impact metrics.

Hosting remains on the existing Vercel project. Publication is separate from local source changes.
